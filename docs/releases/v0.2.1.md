# Sidecar Display 0.2.1

Use a Windows laptop as an extra monitor over your local network.

This first standalone GitHub release removes repetitive interface text, makes the
main window more compact, and adds a Help link. It includes the changed-region
streaming and Ctrl+Shift+F fullscreen controls introduced in 0.2.

## Install

Download **SidecarDisplay-0.2.1-Windows-x64.zip**, verify its SHA-256 against the
attached `.sha256` file, and extract the whole archive on both PCs. Open
`SidecarDisplay.exe`. The .NET runtime and signed virtual display driver are included.
See the [README](https://github.com/kuzeyatay/sidecar-display#readme) for setup.

Requires Intel/AMD 64-bit Windows 10 (1903+) or Windows 11. Sidecar's executable is
unsigned. The virtual display driver needs administrator approval on the sender only.

## Upgrade

Close both copies before replacing files. Keep the sender's path to retain its
firewall rule, or use **Allow private LAN** from the new location. The driver does
not need reinstalling. Restart sharing and copy a new invitation to the receiver.

## Scope and limits

- One receiver on the same local network; no remote keyboard/mouse or audio.
- JPEG streaming without hardware video encoding. Preset frame rates are upper limits.
- Core regression tests and local desktop checks are documented in
  [VERIFICATION.md](https://github.com/kuzeyatay/sidecar-display/blob/main/VERIFICATION.md).
  Two-PC acceptance for this exact build is separate from loopback verification.
